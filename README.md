# Инструмент генерации перечня элементов ПЭ3 и спецификации СП для комплектации и/или закупки из схемы DipTrace. Множество гибких параметров настройки вывода позволяют формировать документы с разными опциями.

## Постоянное название проекта

| RU | Генерация перечня элементов спецификации из схемы DipTrace |

Автономный HTML-инструмент (один файл, без сборки и без интернета) для выпуска перечня элементов (ПЭ3) и спецификации (СП) по ЕСКД из BOM в CSV или схемы DipTrace `.dchxml`.

**Текущая версия:** v23.

**Открыть онлайн:** https://wadi-li.github.io/eskd-csv-pdf/ — или скачать `eskd_csv_pdf.html` и открыть в браузере.

## Возможности

- Вход: CSV (`;`, UTF-8 / windows-1251) или схема DipTrace `.dchxml` с иерархическими блоками (функциональные группы или сквозной список A1-A3-R5).
- Выход: PDF (шрифт ГОСТ 2.304 тип А/Б, прямой или наклонный), XLSX по шаблонам ГОСТ Р 2.104-2023 / ГОСТ 2.701-2008, CSV.
- Перечень по ГОСТ 2.701-2008, спецификация по ГОСТ Р 2.106-2019; основная надпись по формам 2 и 2а ГОСТ Р 2.104-2023, заполнение из схемы.
- Диапазоны позиционных обозначений (C11 - C15), группировка одинаковых номиналов, полное или сокращённое (ShortDesc) наименование, уменьшение шрифта длинных обозначений.
- Наименование ПЭ3 на выбор: p/n; p/n + ShortDesc; p/n + ShortDesc + Производитель; полное (тип, описание, производитель, страна, p/n). Повторы p/n и производителя внутри ShortDesc не дублируются; тип элемента ставится впереди в разделе «Прочие изделия» (по типам) или по переключателю (одним списком). Наименование СП на выбор: p/n; p/n, ShortDesc; p/n, ShortDesc, Производитель; p/n + (ShortDesc, Производитель) — по умолчанию, в том числе при выборе непустого примечания.
- Примечание (ПЭ3 и СП): пусто, производитель, производитель + ShortDesc, коды заказа K/L, технический код O, имя в базе (elixml), корпус (libxml), имя файла 3D модели (из посадочного места .dchxml).
- Разделы по типам элементов: микросхемы, диоды и TVS, конденсаторы, резисторы, индуктивности, прочие изделия; резисторы 0 Ом (перемычки, страпы, p/n …-070RL) в ПЭ3 относятся к прочим изделиям.
- Исключение KR*, KT*, Рис.* и элементов «не уст.», «место под перемычку».
- Литера по ГОСТ 2.103-2013 (как в схеме или из таблицы, О₁/О₂ с индексом).
- Лист регистрации изменений по ГОСТ Р 2.503-2023 (прил. Б, форма 3) последним листом с учётом в нумерации.
- Дополнительная надпись над основной (разработчик, дата, время, «ЧЕРНОВИК», «НА СОГЛАСОВАНИЕ», свободный текст).
- Языки документов RU/UK, интерфейс RU/UK/EN; светлая тема по умолчанию, переключение на тёмную; сохранение настроек в XML.

## Изменения

### v23
- «Наименование СП» — выпадающее меню: p/n; p/n, ShortDesc; p/n, ShortDesc, Производитель; p/n + (ShortDesc, Производитель).
- Вариант «p/n + (ShortDesc, Производитель)» выбран по умолчанию и включается при выборе непустого примечания, если наименование СП не меняли вручную.

### v22
- Раздел «Прочее» переименован в «Прочие изделия» (ПЭ3 и СП).
- Резисторы 0 Ом в ПЭ3 относятся к разделу «Прочие изделия».
- «Наименование ПЭ3» — выпадающее меню: p/n; p/n + ShortDesc; p/n + ShortDesc + Производитель; полное (старый алгоритм).
- «Примечание» дополнено пунктами: производитель, производитель + ShortDesc, корпус (libxml), имя файла 3D модели; «Пусто» теперь всегда пустое.

### v21
- СП в режиме ShortDesc при примечании «Пусто»: «Наименование» — ShortDesc, «Примечание» — производитель (как в ПЭ3).

### v20
- Заголовки «Формат» и «Зона» в СП выровнены по центру графы.
- Номер листа на 2-м и следующих листах PDF крупнее примерно на 40 %.
- Новые правила граф «Наименование» и «Примечание» для ПЭ3 в режиме ShortDesc.
- Переключатель «При выводе ПЭ3 одним списком добавлять перед кратким описанием тип элемента».

## Ограничения

- XLSX хранит только имя шрифта: ГОСТ-шрифт должен быть установлен в Windows.
- Лист регистрации изменений формируется только в PDF.
- Увеличенный номер листа сделан в PDF; в XLSX номер листа оформляется по шаблону.
- Имя файла 3D модели доступно только для схемы .dchxml (в CSV его нет; для автоматических моделей IPC-7351 графа пустая).
- Проверено в Chrome; печать на бумаге и Microsoft Excel не проверялись.
