# Генерация перечня элементов спецификации из схемы DipTrace

## Постоянное название проекта

Использовать эти названия в каталоге, README и ссылках. Менять их только по прямому указанию владельца; описание возможностей не является новым названием.

| Язык | Название |
| --- | --- |
| RU | Генерация перечня элементов спецификации из схемы DipTrace |
| UA | Генерація переліку елементів і специфікації зі схеми DipTrace |
| EN | Generate parts lists and specifications from a DipTrace schematic |
| FRA | Génération de nomenclatures et spécifications depuis un schéma DipTrace |


Автономный HTML-инструмент (один файл, без сборки и без интернета) для выпуска перечня элементов (ПЭ3) и спецификации (СП) по ЕСКД из BOM в CSV или схемы DipTrace `.dchxml`.

**Открыть онлайн:** https://wadi-li.github.io/eskd-csv-pdf/ — или скачать `eskd_csv_pdf.html` и открыть в браузере.

## Возможности

- Вход: CSV (`;`, UTF-8 / windows-1251) или схема DipTrace `.dchxml` с иерархическими блоками (функциональные группы или сквозной список A1-A3-R5).
- Выход: PDF (шрифт ГОСТ 2.304 тип А/Б, прямой или наклонный), XLSX по шаблонам ГОСТ Р 2.104-2023 / ГОСТ 2.701-2008, CSV.
- Перечень по ГОСТ 2.701-2008, спецификация по ГОСТ Р 2.106-2019; основная надпись по формам 2 и 2а ГОСТ Р 2.104-2023, заполнение из схемы.
- Диапазоны позиционных обозначений (C11 - C15), группировка одинаковых номиналов, полное или сокращённое (ShortDesc) наименование, уменьшение шрифта длинных обозначений.
- Исключение KR*, KT*, Рис.* и элементов «не уст.», «место под перемычку».
- Литера по ГОСТ 2.103-2013 (как в схеме или из таблицы, О₁/О₂ с индексом).
- Лист регистрации изменений по ГОСТ Р 2.503-2023 (прил. Б, форма 3) последним листом с учётом в нумерации.
- Дополнительная надпись над основной (разработчик, дата, время, «ЧЕРНОВИК», «НА СОГЛАСОВАНИЕ», свободный текст).
- Языки документов RU/UK, интерфейс RU/UK/EN; светлая тема по умолчанию, переключение на тёмную; сохранение настроек в XML.

## Ограничения

- XLSX хранит только имя шрифта: ГОСТ-шрифт должен быть установлен в Windows.
- Лист регистрации изменений формируется только в PDF.
- Проверено в Chrome; печать на бумаге и Microsoft Excel не проверялись.
