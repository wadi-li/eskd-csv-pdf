2Основная надпись

Расшифровка литер (ГОСТ 2.103-2013, табл. 1)
Щелчок по строке — выбрать литеру. Проектная КД — литеры П, Э, Т; рабочая КД — без литеры, О, О₁, О₂, А, Б, И. Литеры О₂ и Б применяют для изделий по заказу Минобороны.
Дополнительная надпись над основной надписью (PDF)
Дата и время — на момент выгрузки PDF. Надпись размещается слева над основной надписью на всех листах; ГОСТ её не требует.
ГОСТ Р 2.503-2023, прил. Б, форма 3. ЛРИ — последний лист, учитывается в графе «Листов» и в нумерации (PDF).

Иерархия схемы
Для схем DipTrace с иерархическими блоками. Функциональные группы — по ГОСТ 2.701-2008 п. 5.7.7 и ГОСТ 2.702-2011 п. 5.3.13: обозначения внутри одинаковых групп повторяются, элементы группы записываются отдельным разделом с подчёркнутым заголовком, количество — на одну группу, число групп — в строке заголовка. Сквозной список — каждый физический элемент с полным обозначением по ГОСТ 2.710 (A1-A3-R5). В спецификации количество всегда считается по физическим элементам.
Формат подблока
Длинные обозначения
Формат подблока — запись составного обозначения в сквозном списке и обозначений групп. A1-A4-R5 — по ГОСТ 2.710; остальные варианты — внутренние соглашения предприятия. «Уменьшать шрифт»: если обозначение (или диапазон) не помещается в ширину графы, кегль этой ячейки уменьшается, но не ниже 1,8 мм для шрифта типа Б и 2,5 мм для типа А (ГОСТ 2.304-81 п. 2.2); если и так не помещается — перенос.
Полное: тип, описание, производитель, страна, p/n. Сокращённое: только поле ShortDesc (доп. поле компонента DipTrace или столбец ShortDesc в CSV); при пустом ShortDesc остаётся полная запись.
